# NEXUS Playground

A live code playground. Type it, run it, see it — right on your phone. Built by DoubleA @ AntManThePro.

Live: https://nexus-playground-doublea.netlify.app/

How to use:
1. Open the link. Code goes on the left, preview on the right.
2. Pick HTML or React up top. HTML mode works offline; React mode needs internet for its CDN.
3. Hit Sample React or Sample HTML to start from something that runs, then make it yours.
4. Save a snippet to keep it, or Download code to take it with you.

Links: [live site](https://nexus-playground-doublea.netlify.app/) · [NEXUS hub](https://nexus-world-hub.netlify.app/) · [repo](https://github.com/AntManThePro/nexus-playground)
